# Imagens de fundo

Coloque aqui imagens `.jpg`, `.png` ou `.webp` (ideal: 1920x1080 ou maior).

- Cada lição escolhe automaticamente uma imagem desta pasta (sempre a mesma para a mesma lição).
- Para fixar uma imagem específica numa lição, use `"background": "backgrounds/nome.jpg"` no JSON da lição.
- A imagem recebe escurecimento + desfoque automáticos para o texto ficar legível (ajuste em `backgrounds.darken` e `backgrounds.blur` no config.yaml).
- **Se a pasta estiver vazia, nada quebra**: o sistema gera gradientes procedurais bonitos por conta própria.

Fontes gratuitas de imagens (licença livre para uso comercial):
- https://www.pexels.com
- https://unsplash.com
- https://pixabay.com
